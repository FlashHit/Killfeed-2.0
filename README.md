# Killfeed-2.0

A new killfeed for [Venice Unleashed](https://veniceunleashed.net/) that displays more information compared to the default in-game kill feed.

## Features

- Headshot icon
- Roadkill icon
- Player connected message
- Player disconnected message

[For more information visit the VU community forum](https://community.veniceunleashed.net/t/killfeed-2-0)
